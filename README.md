# WC India Hub 2026 🏆

**FIFA World Cup 2026 Dashboard for Indian Fans** — Built with Streamlit, Python, and Pandas.

**Live Schedule • IST Timings • Predictions • Analytics Dashboard**

## Features
- Accurate IST match timings for Indian viewers
- Interactive predictions + ML model stub
- Data visualizations with Plotly
- Monetization-ready (affiliates, ads)
- Educational resources for students

## Tech Stack
- **Frontend**: Streamlit
- **Data**: Pandas, Plotly, openfootball JSON
- **DevOps**: Docker, GitHub Actions CI/CD
- **ML**: scikit-learn (in progress)

## Quick Start
```bash
pip install -r requirements.txt
streamlit run wc_india_hub.py
